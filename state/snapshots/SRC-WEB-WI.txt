Administrative Register
The Wisconsin Administrative Register is the official publication of the updates and changes of the
Wisconsin Administrative Code
.
Go to current register.
Go to most recent end-of-month register.
Each end-of-month (B) Register contains an
Archive
of inserted and removed code chapters and final rulemaking orders.

This includes all chapters and related rulemaking orders that were inserted, removed, or published in the given register.
