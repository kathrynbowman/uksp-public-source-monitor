Rhode Island State Rules and Regulations
The Rhode Island Code of Regulations (RICR) is an online, uniform code that provides access to all proposed and final regulations filed by State agencies, boards, and commissions under the State's Administrative Procedures Act to make government more transparent, accessible, and efficient.
